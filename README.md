# 人生日历 · Life Calendar

一个可以记录每天工作、安排明天计划的三级日历网站。整个网站就是一本大日历：**年 → 月 → 日**。

日历内容不写入浏览器缓存，而是直接保存在你选择的 Markdown 文件里：第一次选好保存位置后，每次修改都会自动同步到该文件；也可以打开已有 MD 继续编辑。

## 功能

- **年份总览**：2006 – 2105 共 100 年，按年代分组展示；有记录的年份带圆点标记，当前年份高亮。
- **年页面**：填写「年度计划」；12 个月份卡片直接进入对应月份；支持上一年 / 下一年；「回顾上一年」可展开查看上一年的计划并跳转。
- **月页面**：填写「月计划」；按周一至周日排列的日期网格，点击进入某一天；支持上月 / 下月；「回顾上个月」查看上月计划。
- **日页面**：记录「今日心情」「今日天气」（带天气小图标）、覆盖工作与生活的「今日记录」、值得记住的小事；明日计划保持轻量，写一两件事即可。支持昨天 / 明天；「回顾昨天」会展示当天的心情、天气、记录、小事和当时的明日计划。
- **三级记账**：日页面日期标题旁的小「¥」按钮打开完整记账页，逐笔填写物品与价格并统计当日支出；月页面、年页面也用同样的「¥」入口，点击后查看月度或年度收支详情。月详情可填写本月收入并查看每日支出与净收入；年详情汇总 12 个月的支出、收入与全年净收入。记账内容随 MD 文件一起保存。
- **找电影**：日页面记账入口左侧的胶片按钮全屏打开「找电影」页面（和影片详情页一样铺满视口，关闭按钮在右上角）。片库是**双源**：不填任何东西时用 **Cinemeta**（免 Key、免注册，覆盖 IMDb 全量影片，翻到第几千条仍正常，片名为英文），填一个免费 TMDB Key 后切到 **TMDB 中文库**（中文片名 / 简介 / 评分，discover 最多 500 页 × 20 条）。类型 / 地区 / 年代 / 评分（9 分以上 … 6 分以上）/ 排序（综合、评分、评价人数、最新上映）都可筛选，滚动到底自动加载下一页；每次打开页面首屏会在整个片库的所有页里均匀随机（TMDB 500 页、Cinemeta 200 页全都算，冷门片所在的深页同样会被推到首屏）；看过的影片会跨会话、跨片源持久记一份，重开页面、刷新页面或切换片源后都不会再推同一批；顶部「TMDB · 中文 / Cinemeta · 英文」两个按钮随时切换片源（Cinemeta 免 Key）；「换一批」只换电影、绝不改动你选的筛选条件，并优先挑出本次还没展示过的影片（豆瓣的匿名接口点两下就 302 跳登录页，已弃用）。点海报或片名会用本地排版直接展示影片资料（评分、时长、类型、导演、主演、简介），并给出「在豆瓣搜这部片」与「IMDb / TMDB 条目」两个直达链接；每部片都有「想看」「看过」两个选项，两份清单入口在**右上角**，清单页同样带搜索、排序（收藏时间 / 评分 / 年份 / 片名）与类型 / 地区 / 年代 / 评分筛选。清单里的搜索会**自动在中文名与英文名之间互查**：关键词先做本地匹配（片名、原名、年份、类型、地区、两套 id），没有直接命中时把关键词交给两个片源解析出候选片名与 id，再按 id / 片名与收藏对齐——中文搜「盗梦空间」找得到只存了英文名 `Inception` 的 Cinemeta 条目，英文搜 `Inception` 也找得到只存了中文名的 TMDB 条目；Cinemeta 的检索本身认中文别名，所以不填 Key 也能用，断网时退回纯本地匹配。标记为「想看」或「看过」的影片不再出现在推荐流里（搜索时仍能搜到、也能取消收藏）。两个片源对同一部片用「IMDb id / TMDB id / 中英文片名 + 年份」认片，并把两套 id 一起存进 MD：TMDB 中文名与 Cinemeta 英文名对不上也不会重复收藏，换片源后也不会把已收藏的片再推荐出来；清单里已经存在的重复条目会在打开页面和导入 MD 时自动合并成一条。详情页右上角的跳转徽标会随条目所属片源显示 TMDB 或 IMDb。
- **Typora 式即时渲染**：年度计划、月计划、今日记录、值得记住的小事、明日计划等**所有可输入笔记的字段**都使用 Vditor 的 IR（即时渲染）模式。边写边看到排版效果，Markdown 语法标记只在当前编辑块显示；支持标题、表格、任务列表、代码块、引用、链接、图片等，回顾面板也按 Markdown 展示。
- **天气动画**：选定天气后，动画以半透明图层从页面顶端一直覆盖到心情选择的上边界，不额外占用一块区域——晴天阳光以半透明浮在文字上方；云层由多层柔边云团组成，有体积感并缓慢明暗流动；雨雪带远近景深，雨丝倾斜、落地有水花，雪花会飘摆旋转，并时不时飘过一两片带分叉的大雪花；雷雨会密集落雨并偶尔触发闪电。尊重「减少动态效果」设置。
- **主题色**：6 个预设色 + 任意自定义颜色，默认粉色；强调色文字会自动校验对比度（≥ 4.5:1），主题色随文件一起保存和恢复。
- **自动同步**：选好 MD 保存位置后，编辑停止约 0.5 秒即写入文件；导出、切换页面和写入文件前会先提交编辑器里尚未回调的输入，避免最后几个字丢失；主题色变化也会同步。
- **恢复连接**：文件句柄保存在 IndexedDB（只存句柄，不存日历内容），下次打开页面会自动读取上次的文件；若浏览器要求重新授权，点击「恢复同步」即可。
- **打开 / 导出**：点击「打开 MD」用浏览器文件选择框读取已有文件，桌面、手机、GitHub Pages 等 HTTPS 静态托管下都可用；也可以把 `.md` 文件直接拖进页面导入。导入后如需继续自动同步，点「选择保存位置」选中同一个文件即可。即使某个环境不弹出文件选择框，状态栏也会在几秒内给出提示，不会毫无反应。「导出副本」随时下载一份快照。
- **日历正确性**：月份天数与闰年规则全部由 `Date` API 计算（含 2100 这类整百年平年），日期夹取到合法范围。
- **动效**：仅使用 `transform` / `opacity` 的 CSS 过渡与入场动画，并尊重 `prefers-reduced-motion`。

## 使用流程

1. 点击顶部「选择保存位置」，选择 `人生日历.md` 要保存的目录和文件名（可新建或覆盖）。
2. 正常填写年 / 月 / 日计划，修改会自动同步到该文件，顶部显示「已同步」。
3. 下次打开网页，应用会尝试自动恢复上次的文件；若浏览器询问权限，点击「恢复同步」。
4. 已有 MD 文件时，点击「打开 MD」选择文件读取内容；也可以直接把 `.md` 拖进页面。导入后如需自动同步，点击「选择保存位置」选中同一个文件。
5. 需要额外备份时，点击「导出副本」下载一份 Markdown。

自动同步依赖 **File System Access API**，推荐使用 Chrome / Edge。Safari、Firefox、手机浏览器或受限环境会退化为「打开 MD + 导出副本」，此时页面顶部会明确提示，未导出的修改在关闭前会提醒。GitHub Pages 等 HTTPS 静态托管上，「打开 MD」与拖拽导入始终可用；电影片库仍需要本地运行 `serve.py`。

## 数据与隐私

- 年 / 月 / 日内容只写入你选择的本地 MD 文件，不上传到任何服务器。
- 浏览器中只保存一个文件句柄（用于下次恢复连接），不保存日历正文；清理站点数据会丢失这个连接，需要重新选择文件。
- 未连接文件时，内容只存在于当前标签页内存中，刷新会丢失，请及时选择保存位置或导出。
- 找电影由浏览器直连片源的公开接口（TMDB 的 `api.tmdb.org`，或免 Key 的 Cinemeta `v3-cinemeta.strem.io`）取影片资料与海报，请求只包含筛选条件或关键词，不包含你的日记内容。TMDB API Key 只存在你这台浏览器的 localStorage，不写进 MD，也不经过任何第三方中转。

## 数据文件格式

导出的文件是普通 Markdown，可直接用编辑器阅读和修改；再次打开时会重新解析。示例：

```markdown
# 人生日历

> 此文件由「人生日历」生成，可直接导入网站恢复记录。

- 格式版本：10
- 导出时间：2026-11-24 18:30
- 主题色：#e26a8d

## 想看的电影

- 沙丘 2 · 2024 · 8.2 · tmdb=693134 · 2026-11-24 · 类型=科幻/冒险 · 地区=美国 · 原名=Dune: Part Two

## 看过的电影

- 肖申克的救赎 · 1994 · 9.7 · 1292052 · 2026-11-24 · 类型=剧情/犯罪 · 地区=美国

## 年度 · 2026

### 年度计划

读完 24 本书。

### 月份 · 2026-03

#### 月计划

完成日历项目。

#### 本月收入

10000.00

#### 日期 · 2026-03-05 · 星期四

##### 今日心情

不错

##### 今日天气

晴

##### 今日记录

上午写完了年 / 月 / 日三级页面，下午去公园散步。

##### 值得记住的小事

公园的晚霞
读完一章书

##### 今日支出

- 25.50 元 · 咖啡
- 38.00 元 · 午餐

##### 明日计划

补测试，发布到 GitLab。
```

- 章节标题（`##` / `###` / `####` / `#####`）决定层级；计划正文可以包含任意多行文本。
- 正文中若某行以 `#` 或 `\` 开头，写入文件时会自动加 `\` 转义，重新读取时原样还原，保证往返不丢内容。
- 导出会保留正文的首行缩进、代码块与空行；读取只会跳过结构性的空白，不会改写正文内容。
- 心情、天气、今日记录、值得记住的小事、今日支出、明日计划、月计划、本月收入、年度计划，以及「想看的电影」「看过的电影」两份清单全部写入文件；导入后逐项恢复。
- 文件版本记录在 `- 格式版本：10`；读取时会跳过 2006–2105 之外或不合法的日期，并在顶部提示跳过数量。
- 没有内容的年 / 月 / 日不会写入文件；旧版文件里的「今日工作记录」「明日工作计划」仍可读取，会分别归入「今日记录」和「明日计划」。
- 记账金额以元为单位、精确到分；支出行格式为 `- 金额 元 · 物品`，月收入写在 `#### 本月收入` 下。
- 电影清单写在顶层 `## 想看的电影` / `## 看过的电影` 下，行格式为 `- 片名 · 年份 · 评分 · tmdb=550 或 IMDb id · 加入日期 · 海报地址 · 类型=剧情/犯罪 · 地区=美国 · 原名=Fight Club · imdb=tt0137523`；除片名外都可省略。TMDB 数字 id 写成 `tmdb=` 前缀，回读时不会被误认成上映年份；旧文件里的裸数字 id 仍可识别。类型与地区是收藏时从片源补上的，清单页的筛选就靠这两个字段；没有它们的旧条目只会被「全部」匹配，联网收藏新的影片后自动补齐。原名与 IMDb id 只在和展示字段不同时写入，用来把 TMDB 与 Cinemeta 两套 id 里的同一部片认成一部：换片源不会重复收藏，也不会再被推荐。旧版文件里的 `##### 今日电影`（今日片单）会在导入时迁移进「看过的电影」，日期取当天。更早用豆瓣片源收藏的条目存的是豆瓣 id 与 doubanio 海报（外链会被 403），打开「想看的电影 / 看过的电影」时会自动按片名 + 年份回查当前片源，换成可用的 id 与海报并写回 MD。两个片源重复收藏的同一部片会在导入 MD、打开找电影和每次标记收藏时自动合并：优先保留「看过」的那一条，两套 id、原名、类型、地区与更早的收藏日期都会合并保留。

## 本地运行

仓库自带一个零依赖的本地服务 `serve.py`，只做两件事：托管静态文件（`index.html`、`assets/…`）和提供本机停止接口。它不再代理任何第三方数据——「找电影」由浏览器直连 TMDB，所以不启动它也能找电影（用任意静态服务器或 GitHub Pages 都行），启动它只是为了让双击 `.vbs` 的流程能自动开浏览器、并能优雅停止。

双击 `启动人生日历.vbs` 后台启动（不弹命令行窗口）并自动打开浏览器；双击 `停止人生日历.vbs` 停止。不会写入任何开机启动项。

```bash
python serve.py                 # 前台启动，显示日志并自动打开浏览器
python serve.py --no-browser    # 只启动，不打开浏览器
python serve.py --port 8080     # 换端口
python serve.py --host 0.0.0.0  # 允许局域网访问
```

- 只需要 Python 3.8+，不需要安装任何包。
- 「找电影」不走这个服务：浏览器直接请求片源，所以页面用 `file://` 打开、用别的静态端口打开、或托管在 GitHub Pages 上都能用；服务没启动只影响它自己托管页面这件事。
- 打开日页面时会在空闲时段**预热**找电影的首屏（预热的正是稍后全屏页会随机落到的那一页），点胶片按钮时列表已在内存里，不用等接口往返。
- 找电影**不再依赖** `serve.py`：片源直连 TMDB，所以页面放在 GitHub Pages 等远端 https 站点、或用 `file://` 直接打开时，找电影一样能用。
- 不填 Key 也能用（Cinemeta 英文全量片库）。想要中文片名 / 简介，就填一次免费的 TMDB API Key：在 www.themoviedb.org 注册后进「设置 → API」，复制「API Key (v3 auth)」粘进右上角的「Key」面板即可。Key 只存在浏览器 localStorage，换浏览器或清理站点数据后需要重填；Key 失效时会自动退回英文片库，不会变成死路。
- **为什么换掉豆瓣**：豆瓣的匿名接口（`j/new_search_subjects`、`j/subject_suggest` 等）对本机 IP 连续请求后会一律 302 跳登录页——点两下「换一批」就再也拿不到数据，且没有可用的替代接口。实测过的替代：TMDB 的 `api.tmdb.org` 国内可直连（返回 401 而不是超时）、带 CORS 头、海报 CDN `image.tmdb.org` 可达，默认 50 次/秒，discover 可翻 500 页，是功能最全的一条（需免费 Key）；Cinemeta 的 `v3-cinemeta.strem.io` 免 Key、无注册、`skip` 到 5000 仍正常、海报 `images.metahub.space` 可达，代价是英文片名（默认源），但它的 `search=` 本身认中文别名（`search=盗梦空间` 就返回 `Inception`），所以中文检索在没有 Key 时也能换来英文条目；WMDB 实测 10 秒只能搜一次（429），iTunes 中国区电影库返回 0 条，都不足以支撑「换一批」。
- 片库去重按「同一部片」而不是「同一行」：IMDb id、TMDB id、原名 + 年份任一能对上就合并；缺的一边用 Cinemeta 条目页自带的 `moviedb_id` 自动补齐（不需要 TMDB Key）。「杀死比尔」与「Kill Bill: Vol. 1」这类中英文两行只保留一条，清单与入口计数都只算一部；旧版粘在一起的「片名 + 年份 + 评分」行导入时会拆开，粘在评分后的评分人数不会再被误当成 TMDB id。
- 详情页用片源 JSON 本地渲染，整页占满视口、按 TMDB 条目页组织：背景剧照铺满页面顶端并渐隐到页面底色，左侧大海报、右侧标题 / 原名 / 上映日期 / 片长 / 地区 / 类型标签 / 评分环（10 分制弧长）/「想看 · 看过」一屏排开；正文左栏是剧情简介、带演员头像与角色名的演职员横排，右栏是「影片资料」（上映日期、语言、制作公司、预算、票房等）与片源直达链接。860 px 以下收成单列、375 px 手机宽按小海报紧凑排版；返回按钮浮在背景图上，滚动时始终可点。不再内嵌第三方页面，断网或对方改版都不会白屏；「在豆瓣搜这部片」与「TMDB 条目 / IMDb 条目」都是新窗口直达链接。

## 目录结构

```
index.html             页面骨架（顶栏、文件栏、主题色、页脚）
serve.py               本地服务：静态托管 + 本机停止接口（不代理任何第三方数据）
assets/style.css       全部样式与响应式布局
assets/app.js          路由、日历计算、Markdown 读写、文件同步、主题色
assets/movie-source.js 找电影的数据客户端（TMDB 中文库 + 免 Key 的 Cinemeta 英文库）
assets/film-identity.js 同一部片的认定、合并与唯一化（页面与测试共用）
assets/film-record.js  收藏的 MD 行解析 / 生成（导入导出与测试共用）
assets/favicon.svg     站点图标
assets/vendor/         Vditor（IR 编辑器）、marked（回顾解析）与 DOMPurify（安全过滤）
```

## 部署

本站是纯静态站点，可直接放到任意静态托管（Nginx、对象存储、GitHub / GitLab Pages 等）。仓库不包含自动部署流水线；部署后请使用 HTTPS 域名，否则浏览器不会开放文件自动同步能力。
