# 人生日历 · Life Calendar

一个可以记录每天工作、安排明天计划的三级日历网站。整个网站就是一本大日历：**年 → 月 → 日**。

## 功能

- **年份总览**：2006 – 2106 共 101 年，按年代分组展示；有记录的年份带圆点标记，当前年份高亮。
- **年页面**：填写「年度计划」；12 个月份卡片直接进入对应月份；支持上一年 / 下一年；「回顾上一年」可展开查看上一年的计划并跳转。
- **月页面**：填写「月计划」；按周一至周日排列的日期网格，点击进入某一天；支持上月 / 下月；「回顾上个月」查看上月计划。
- **日页面**：填写「今日工作记录」与「明日工作计划」；支持前一天 / 后一天；「回顾前一天」可查看前一天的工作记录和当时写下的明日计划。
- **主题色**：6 个预设色 + 任意自定义颜色，默认粉色；强调色文字会自动校验对比度（≥ 4.5:1）。
- **自动保存**：输入后 300ms 自动写入 `localStorage`，离开页面或切到后台时立即保存。
- **日历正确性**：月份天数与闰年规则全部由 `Date` API 计算（含 2100 这类整百年平年），日期夹取到合法范围。
- **动效**：仅使用 `transform` / `opacity` 的 CSS 过渡与入场动画，并尊重 `prefers-reduced-motion`。

## 本地运行

纯静态站点，无需构建、无需依赖：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

也可以直接双击 `index.html`。

## 目录结构

```
index.html          页面骨架（顶栏、主题色、页脚）
assets/style.css    全部样式与响应式布局
assets/app.js       路由、日历计算、数据存取、主题色
assets/favicon.svg  站点图标
```

## 数据与路由

- 数据保存在浏览器 `localStorage` 的 `life-calendar:v1` 键中，结构为 `年 → 月 → 日`；不会上传到任何服务器。换浏览器或清理站点数据会丢失记录，请自行留意。
- 路由使用 URL hash，可直接收藏或分享到某一页：
  - `#/` 年份总览
  - `#/2026` 年页面
  - `#/2026/3` 月页面
  - `#/2026/3/14` 日页面
- 浏览器前进 / 后退、刷新都会保持当前层级。

## 部署到 GitLab Pages

仓库已包含 `.gitlab-ci.yml`：推送到默认分支后，CI 会把静态文件发布到 Pages（`pages` job）。若项目未启用 Pages，可在 **Settings → Pages** 中开启，或直接把仓库文件放到任意静态托管上。
