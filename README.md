# 人生日历 · Life Calendar

一个可以记录每天工作、安排明天计划的三级日历网站。整个网站就是一本大日历：**年 → 月 → 日**。

数据不写入浏览器缓存或 localStorage，而是保存在一个 Markdown 文件里：网页可以导入 MD 恢复日历，也可以导出 MD 备份全部内容。

## 功能

- **年份总览**：2006 – 2106 共 101 年，按年代分组展示；有记录的年份带圆点标记，当前年份高亮。
- **年页面**：填写「年度计划」；12 个月份卡片直接进入对应月份；支持上一年 / 下一年；「回顾上一年」可展开查看上一年的计划并跳转。
- **月页面**：填写「月计划」；按周一至周日排列的日期网格，点击进入某一天；支持上月 / 下月；「回顾上个月」查看上月计划。
- **日页面**：填写「今日工作记录」与「明日工作计划」；支持前一天 / 后一天；「回顾前一天」可查看前一天的工作记录和当时写下的明日计划。
- **主题色**：6 个预设色 + 任意自定义颜色，默认粉色；强调色文字会自动校验对比度（≥ 4.5:1），主题色随 MD 文件一起保存和恢复。
- **导入 / 导出 MD**：导入文件即恢复整本日历；导出文件即得到可读、可继续导入的完整备份。`Ctrl/Cmd + S` 也可直接导出。
- **修改提示**：编辑后顶部显示「有未导出的修改」，关闭或刷新页面前浏览器会提醒。
- **日历正确性**：月份天数与闰年规则全部由 `Date` API 计算（含 2100 这类整百年平年），日期夹取到合法范围。
- **动效**：仅使用 `transform` / `opacity` 的 CSS 过渡与入场动画，并尊重 `prefers-reduced-motion`。

## 使用流程

1. 在任意年份 / 月份 / 日期填写计划与记录。
2. 点击「导出 MD」，浏览器下载 `人生日历-YYYY-MM-DD.md`（若已导入过文件，则沿用原文件名）。
3. 下次打开网页，点击「导入 MD」选择该文件，全部内容与主题色恢复。

页面内容只存在于当前标签页的内存中。**刷新、关闭或清理标签页都会丢失未导出的修改**，请及时导出。

## 数据文件格式

导出的文件是普通 Markdown，可直接用编辑器阅读和修改；再导回网页时会重新解析。示例：

```markdown
# 人生日历

> 此文件由「人生日历」生成，可直接导入网站恢复记录。

- 格式版本：1
- 导出时间：2026-11-24 18:30
- 主题色：#e26a8d

## 年度 · 2026

### 年度计划

读完 24 本书。

### 月份 · 2026-03

#### 月计划

完成日历项目。

#### 日期 · 2026-03-05 · 星期四

##### 今日工作记录

写完了年 / 月 / 日三级页面。

##### 明日工作计划

补测试，发布到 GitLab。
```

- 章节标题（`##` / `###` / `####` / `#####`）决定层级；计划正文可以包含任意多行文本。
- 正文中若某行以 `#` 或 `\` 开头，导出时会自动加 `\` 转义，重新导入时原样还原，保证往返不丢内容。
- 文件版本记录在 `- 格式版本：1`；导入时会跳过 2006–2106 之外或不合法的日期，并在顶部提示跳过数量。
- 没有内容的年 / 月 / 日不会写入文件。

## 本地运行

纯静态站点，无需构建、无需依赖：

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

也可以直接双击 `index.html`（部分浏览器在 `file://` 下对文件下载有限制，建议用上面的本地服务器）。

## 目录结构

```
index.html          页面骨架（顶栏、导入/导出栏、主题色、页脚）
assets/style.css    全部样式与响应式布局
assets/app.js       路由、日历计算、Markdown 导入/导出、主题色
assets/favicon.svg  站点图标
```

## 部署到 GitLab Pages

仓库已包含 `.gitlab-ci.yml`：推送到默认分支后，CI 会把静态文件发布到 Pages。若项目未启用 Pages，可在 **Settings → Pages** 中开启，或直接把仓库文件放到任意静态托管上。
