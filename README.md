# 人生日历 · Life Calendar

一个可以记录每天工作、安排明天计划的三级日历网站。整个网站就是一本大日历：**年 → 月 → 日**。

日历内容不写入浏览器缓存，而是直接保存在你选择的 Markdown 文件里：第一次选好保存位置后，每次修改都会自动同步到该文件；也可以打开已有 MD 继续编辑。

## 功能

- **年份总览**：2006 – 2105 共 100 年，按年代分组展示；有记录的年份带圆点标记，当前年份高亮。
- **年页面**：填写「年度计划」；12 个月份卡片直接进入对应月份；支持上一年 / 下一年；「回顾上一年」可展开查看上一年的计划并跳转。
- **月页面**：填写「月计划」；按周一至周日排列的日期网格，点击进入某一天；支持上月 / 下月；「回顾上个月」查看上月计划。
- **日页面**：记录「今日心情」「今日天气」（带天气小图标）、覆盖工作与生活的「今日记录」、值得记住的小事；明日计划保持轻量，写一两件事即可。支持昨天 / 明天；「回顾昨天」会展示当天的心情、天气、记录、小事和当时的明日计划。
- **三级记账**：日页面日期标题旁的小「¥」按钮打开完整记账页，逐笔填写物品与价格并统计当日支出；月页面、年页面也用同样的「¥」入口，点击后查看月度或年度收支详情。月详情可填写本月收入并查看每日支出与净收入；年详情汇总 12 个月的支出、收入与全年净收入。记账内容随 MD 文件一起保存。
- **找电影**：日页面记账入口左侧的胶片按钮打开「找电影」。片库是**随站点一起发布的静态数据**（`assets/library/`，约 7800 部，覆盖全部类型 / 地区 / 年代，每部自带本地海报），所以打开网页即可用，**不需要启动任何本地服务**，GitHub Pages 上同样可用。关键词可搜片名、年份、地区、导演、主演；类型 / 地区 / 年代按标签筛选，可按评分最高、最新上映排序，滚动到底自动加载下一页。点海报或片名在弹层内打开条目页（海报、评分、年份、地区、时长、类型、导演、主演、短评），右上角豆瓣图标直达官网条目页。每部片都有「想看」「看过」两个选项，两份清单入口在弹层**右上角**（「想看的电影」「看过的电影」），点进去可以浏览清单；标记为「看过」的电影不再出现在推荐流里。
- **Typora 式即时渲染**：年度计划、月计划、今日记录、值得记住的小事、明日计划等**所有可输入笔记的字段**都使用 Vditor 的 IR（即时渲染）模式。边写边看到排版效果，Markdown 语法标记只在当前编辑块显示；支持标题、表格、任务列表、代码块、引用、链接、图片等，回顾面板也按 Markdown 展示。
- **天气动画**：选定天气后，动画以半透明图层从页面顶端一直覆盖到心情选择的上边界，不额外占用一块区域——晴天阳光以半透明浮在文字上方；云层由多层柔边云团组成，有体积感并缓慢明暗流动；雨雪带远近景深，雨丝倾斜、落地有水花，雪花会飘摆旋转，并时不时飘过一两片带分叉的大雪花；雷雨会密集落雨并偶尔触发闪电。尊重「减少动态效果」设置。
- **主题色**：6 个预设色 + 任意自定义颜色，默认粉色；强调色文字会自动校验对比度（≥ 4.5:1），主题色随文件一起保存和恢复。
- **自动同步**：选好 MD 保存位置后，编辑停止约 0.5 秒即写入文件；导出、切换页面和写入文件前会先提交编辑器里尚未回调的输入，避免最后几个字丢失；主题色变化也会同步。
- **恢复连接**：文件句柄保存在 IndexedDB（只存句柄，不存日历内容），下次打开页面会自动读取上次的文件；若浏览器要求重新授权，点击「恢复同步」即可。
- **打开 / 导出**：点击「打开 MD」用浏览器文件选择框读取已有文件，桌面、手机、GitHub Pages 等 HTTPS 静态托管下都可用；也可以把 `.md` 文件直接拖进页面导入。导入后如需继续自动同步，点「选择保存位置」选中同一个文件即可。即使某个环境不弹出文件选择框，状态栏也会在几秒内给出提示，不会毫无反应。「导出副本」随时下载一份快照。
- **日历正确性**：月份天数与闰年规则全部由 `Date` API 计算（含 2100 这类整百年平年），日期夹取到合法范围。
- **动效**：仅使用 `transform` / `opacity` 的 CSS 过渡与入场动画，并尊重 `prefers-reduced-motion`。

## 使用流程

1. 点击顶部「选择保存位置」，选择 `人生日历.md` 要保存的目录和文件名（可新建或覆盖）。
2. 正常填写年 / 月 / 日计划，修改会自动同步到该文件，顶部显示「已同步」。
3. 下次打开网页，应用会尝试自动恢复上次的文件；若浏览器询问权限，点击「恢复同步」。
4. 已有 MD 文件时，点击「打开 MD」选择文件读取内容；也可以直接把 `.md` 拖进页面。导入后如需自动同步，点击「选择保存位置」选中同一个文件。
5. 需要额外备份时，点击「导出副本」下载一份 Markdown。

自动同步依赖 **File System Access API**，推荐使用 Chrome / Edge。Safari、Firefox、手机浏览器或受限环境会退化为「打开 MD + 导出副本」，此时页面顶部会明确提示，未导出的修改在关闭前会提醒。GitHub Pages 等 HTTPS 静态托管上，「打开 MD」与拖拽导入始终可用；「找电影」同样可用，片库随站点发布，不依赖本地服务。

## 数据与隐私

- 年 / 月 / 日内容只写入你选择的本地 MD 文件，不上传到任何服务器。
- 浏览器中只保存一个文件句柄（用于下次恢复连接），不保存日历正文；清理站点数据会丢失这个连接，需要重新选择文件。
- 未连接文件时，内容只存在于当前标签页内存中，刷新会丢失，请及时选择保存位置或导出。
- 「找电影」的数据是随站点发布的静态片库（`assets/library/`）：浏览、搜索、筛选都只读本地文件，不会向你打开的网页之外发送请求；只有你主动点条目页右上角的豆瓣图标时，才会跳转到豆瓣官网。

## 数据文件格式

导出的文件是普通 Markdown，可直接用编辑器阅读和修改；再次打开时会重新解析。示例：

```markdown
# 人生日历

> 此文件由「人生日历」生成，可直接导入网站恢复记录。

- 格式版本：7
- 导出时间：2026-11-24 18:30
- 主题色：#e26a8d

## 想看的电影

- 沙丘 2 · 2024 · 8.2 · 36501517 · 2026-11-24

## 看过的电影

- 肖申克的救赎 · 1994 · 9.7 · 1292052 · 2026-11-24

## 年度 · 2026

### 年度计划

读完 24 本书。

### 月份 · 2026-03

#### 月计划

完成日历项目。

#### 本月收入

10000.00

#### 日期 · 2026-03-05 · 星期四

##### 今日心情

不错

##### 今日天气

晴

##### 今日记录

上午写完了年 / 月 / 日三级页面，下午去公园散步。

##### 值得记住的小事

公园的晚霞
读完一章书

##### 今日支出

- 25.50 元 · 咖啡
- 38.00 元 · 午餐

##### 明日计划

补测试，发布到 GitLab。
```

- 章节标题（`##` / `###` / `####` / `#####`）决定层级；计划正文可以包含任意多行文本。
- 正文中若某行以 `#` 或 `\` 开头，写入文件时会自动加 `\` 转义，重新读取时原样还原，保证往返不丢内容。
- 导出会保留正文的首行缩进、代码块与空行；读取只会跳过结构性的空白，不会改写正文内容。
- 心情、天气、今日记录、值得记住的小事、今日支出、明日计划、月计划、本月收入、年度计划，以及「想看的电影」「看过的电影」两份清单全部写入文件；导入后逐项恢复。
- 文件版本记录在 `- 格式版本：7`；读取时会跳过 2006–2105 之外或不合法的日期，并在顶部提示跳过数量。
- 没有内容的年 / 月 / 日不会写入文件；旧版文件里的「今日工作记录」「明日工作计划」仍可读取，会分别归入「今日记录」和「明日计划」。
- 记账金额以元为单位、精确到分；支出行格式为 `- 金额 元 · 物品`，月收入写在 `#### 本月收入` 下。
- 电影清单写在顶层 `## 想看的电影` / `## 看过的电影` 下，行格式为 `- 片名 · 年份 · 评分 · 豆瓣 id · 加入日期 · 海报地址`；年份、评分、豆瓣 id、日期、海报都可省略。旧版文件里的 `##### 今日电影`（今日片单）会在导入时迁移进「看过的电影」，日期取当天。

## 本地运行

本站是纯静态站点：「找电影」用的是随仓库发布的片库，**不需要任何本地服务**。仓库里的 `serve.py` 只是为了方便用 http 打开页面（比 `file://` 少一层浏览器限制）：

- 双击 `启动人生日历.vbs`：后台用 `pythonw` 启动，不弹命令行窗口，并自动打开浏览器。
- 双击 `停止人生日历.vbs`：优雅停掉后台服务（先请求 `/api/stop`，失败再按命令行结束对应进程）。

```bash
python serve.py                # 前台启动，显示日志并自动打开浏览器
python serve.py --no-browser   # 只启动，不打开浏览器
python serve.py --port 8080    # 换端口
python serve.py --host 0.0.0.0 # 允许局域网访问
```

- 只需要 Python 3.8+，不需要安装任何包。**不装 Python 也能用**：把仓库放到任意静态托管（GitHub Pages / Nginx / 对象存储）或直接用浏览器打开即可。
- **没有开机自启**：不会写启动文件夹、不会常驻后台；不需要时关掉窗口或双击停止脚本即可。
- 不运行 `serve.py` 时日历、记账、MD 同步、「找电影」全部正常。
- `http://localhost` / `http://127.0.0.1` 属于安全上下文，可以使用文件选择与自动同步；直接双击 `index.html` 时部分浏览器会禁用该能力，只能用「打开 MD / 导出副本」。

### 更新片库

片库是静态快照，需要新片时重新抓取并提交：

```bash
python tools/build_library.py discover   # 按类型 / 地区 / 年代抓列表
python tools/build_library.py cards      # 抓完整卡片（年份 / 地区 / 导演 / 主演）
python tools/build_library.py posters    # 下载海报并压缩成 WebP
python tools/build_library.py pack       # 合成 assets/library/movies.json
```

需要 `Pillow`（仅海报压缩会用到）。抓取有节流，全部跑完约 15 分钟，中间可随时中断，缓存保留在 `.cache/library/`。

## 目录结构

```
index.html             页面骨架（顶栏、文件栏、主题色、页脚）
serve.py               本地预览服务器（纯静态托管 + /api/stop）
tools/build_library.py 生成自带电影片库的抓取脚本
assets/style.css       全部样式与响应式布局
assets/app.js          路由、日历计算、Markdown 读写、文件同步、主题色
assets/movie-source.js 找电影：读取自带片库，本地搜索 / 筛选 / 排序
assets/library/        电影片库 movies.json + p/*.webp 海报
assets/favicon.svg     站点图标
assets/vendor/         Vditor（IR 编辑器）、marked（回顾解析）与 DOMPurify（安全过滤）
```

## 部署

本站是纯静态站点，可直接放到任意静态托管（Nginx、对象存储、GitHub / GitLab Pages 等）。仓库不包含自动部署流水线；部署后请使用 HTTPS 域名，否则浏览器不会开放文件自动同步能力。
